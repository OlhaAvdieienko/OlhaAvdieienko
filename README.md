## About me

I am a **QA Engineer** with experience in testing web and mobile products, APIs and hardware-integrated systems. My work combines functional, regression, exploratory and integration testing with requirements analysis and technical specifications.

I investigate defects, maintain test documentation and work with clients, developers and designers to clarify product behavior. Alongside QA, I gather and analyze requirements, assess the capabilities of existing systems and identify changes needed for integrations.

My product experience includes queue management and appointment systems, web and mobile services, and self-service terminals. Earlier, I worked in manufacturing quality control and tested browser and desktop games.

## QA and analysis

- **Manual testing:** functional, regression, exploratory and integration testing; business logic, permissions, user flows and interface checks.
- **API and integrations:** testing REST APIs and data exchange with Postman and Swagger; assessing available API methods and required integration changes.
- **Defect investigation:** analyzing network traffic and logs with Chrome DevTools, HTTP Toolkit and ADB; reproducing defects and verifying fixes.
- **Test documentation:** test cases, checklists, bug reports, test summaries and user guides maintained in Jira and Confluence.
- **Requirements and specifications:** gathering and agreeing on client requirements; documenting business rules, constraints and acceptance criteria with existing system capabilities in mind.
- **User flows and mockups:** preparing scenarios, mockups and prototypes to clarify requirements with clients, developers and designers.
